# AetherWeb — Website starter

A responsive one-page website for AetherWeb, built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — layout, responsive styles and animations
- `script.js` — mobile navigation, reveal effects and contact email draft
- `assets/aetherweb-hero.png` — generated hero artwork

## Preview
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository named `aetherweb`.
2. Upload every file and folder in this project (keep the `assets` folder).
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.

## Important before launch
- The portfolio items are clearly labelled concept projects. Replace them with real work as you create it.
- The contact form opens the visitor's email app with a pre-filled message. It does not silently submit to a server. Test it on a device with an email app configured.
- Update the page title, description, project examples and contact details if they change.
- Test on mobile and desktop before sharing the link.
